Tailwind CSS Refresher

Tailwind is a utility-first CSS framework. Every class usually represents one CSS declaration. Instead of writing CSS rules, you compose lots of small utility classes.

Basic Syntax

Tailwind utilities generally follow this pattern:

Pattern Meaning Example
property-value A utility class p-4, text-xl, bg-primary
prefix:utility Apply only in a specific state or breakpoint hover:bg-primary, md:flex
  • p-4 → padding
  • px-6 → horizontal padding
  • py-2 → vertical padding
  • m-8 → margin
  • mt-4 → margin-top
  • w-full → width: 100%
  • h-screen → height: 100vh
  • bg-primary → background colour
  • text-white → text colour
  • rounded-xl → border radius

Responsive Prefixes

Prefixes apply utilities once a breakpoint is reached.

  • md:

Resize the window.

State Prefixes

Prefixes can also target different states.

Common Prefixes

Prefix Purpose Example
hover: Hover state hover:bg-primary
focus: Focused element focus:ring
active: Active (pressed) active:scale-95
disabled: Disabled element disabled:opacity-50
sm: → 2xl: Responsive breakpoints lg:grid-cols-3
dark: Dark mode dark:bg-black
first:, last:, odd:, even: Structural pseudo-classes odd:bg-surface
group-hover:, peer-invalid: Parent/sibling state group-hover:block
